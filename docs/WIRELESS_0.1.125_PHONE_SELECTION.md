# DiPlay 0.1.125 无线 CarPlay 多手机切换测试版

## 本次更新

- **多台已配对的 iPhone 同时在场时，优先连接上次成功投屏的手机。** 首选手机不可达、明确缺少配对密钥或蓝牙确认没有 iAP2 服务时，继续检查其他已配对手机。只有一台可用时，开机连接流程会自动选中它。首次使用仍需完成蓝牙配对和 CarPlay 授权。
- **投屏失败后按顺序尝试其他手机。** 首选机在 iAP2 或首帧前出现确认的连接失败时，会先释放旧会话，再尝试本轮尚未排除的设备。等待超时和旧连接回调会先核对当前会话。正在投屏时保持当前手机，主动点击「停止」会取消排队中的换机。
- **绑定 AirPlay 投屏身份。** 记住成功出画面的手机及其控制器身份，旧手机的预连接消息无法代替目标手机确认投屏。修复了蓝牙配对工作线程在停止连接时未正常退出的问题。
- 自上一公开版以来合入了 ALSA 麦克风采集回退、通话下行使用车机媒体音量通道，以及独立导航音频通道的自动识别。

## 设备与验证

- Android 4.2.2 / API 17，`armeabi-v7a`，包名为 `local.headunit.diplay.hybrid`，版本号 `0.1.125-phone-selection-test`，versionCode 126。
- 项目实车基准是 **2018 款比亚迪宋 DM**，Freescale MX9A0 车机，固件 `V4.2.2.30.170830`，iPhone 15 Pro Max / iOS 26.2.1。无线实车基准使用 **绿联 CM591（`10D7:B012`）** 和车机 Wi-Fi Direct。CM390（RTL8761BU）保留适配代码。
- 本版通过 348 项本地 JVM 回归测试和 API 17 APK 签名校验。多手机选机、首帧前掉线后接续、不同车机与适配器的表现待实车验证。

## 安装与反馈

- 从 GitHub Releases 下载 APK。附件 `SHA256SUMS-wireless-v0.1.125-phone-selection-test.txt` 提供 SHA-256 校验值。APK 继续使用现有无线版签名。
- 停车测试时可让两台已配对手机同时在场，核对是否先连上次投屏的手机，再让首选手机离开范围，观察剩余手机是否自动接续。
- 应用中的兼容性报告按用户主动确认提交至维护者的私人服务器。报告可能包含系统和车型、声卡、按键与连接诊断，短时麦克风测试录音由用户单独选择。旧车机使用 HTTP 上传。

项目基于 [shihabal3amri/DiPlay](https://github.com/shihabal3amri/DiPlay)，无线 USB 蓝牙实现沿用 GPL-3.0 路线与既有第三方声明。对应源码和构建方式见 [该版本标签](https://github.com/hange3514/DiPlay-API17/tree/wireless-v0.1.125-phone-selection-test/legacy-wireless)。
