# 兼容性反馈与隐私

## 怎么提交

有线 0.44.52 在「问题反馈」提交，无线 0.1.117 在「提交日志」提交。在停车时复现问题，再写下现象，例如「打电话双方都听不到」或「方向盘下一曲不响应」。确认提交后，应用会显示服务端回执。

## 同一份报告包含什么

- **车机和固件。** 读取 Android API、车机型号、主板、显示参数、可读取的原厂车型代码、固件和原厂服务版本。车型代码未公开时以未知记录，可继续用车机配置和声卡信息比对。
- **ALSA 和通话。** 声卡、PCM 节点、权限、尝试的输入路径、失败阶段和回退记录。对通话下行还可记录音频格式、电平、路由、写入量及播放头。这些是软件侧证据，车内和通话对端的实际听感由问题描述反映。
- **方向盘。** 接收器状态、原厂按键广播的可识别字段，以及应用收到的媒体、音量、电话、语音和部分厂商按键的键值与转发结果。有按键事件时才能判断具体按键经过哪条路径。
- **连接。** USB、组网和投屏阶段的状态、耗时及错误摘要。有线版在 AirPlay 请求处理器异常时可附带该次失败请求的有限内容、错误详情和已收到的手机标识。无线版可单独选择附带主动准备的短时麦克风测试录音或其他诊断附件。

诊断报告仅在用户主动确认后发送。旧车机上传接口使用 HTTP，数据提交至维护者的私人服务器。服务器报告保留至手动清理。应用核对回执后清理已确认上传的本地条目。

## 项目的实车范围

目前实车参考为 **2018 款比亚迪宋 DM**、Freescale MX9A0、Android 4.2.2 / API 17、1024 × 600，iPhone 15 Pro Max / iOS 26.2.1。无线实车使用绿联 CM591（`10D7:B012`）。同车型的不同车机固件、声卡和按键路径也可能不同。
