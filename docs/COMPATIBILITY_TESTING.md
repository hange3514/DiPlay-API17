# 车型兼容测试

## 版本发布方式

- **0.40.0** 是最后一个有完整实车验证记录的稳定 APK，也是已确认可用的有线基线：比亚迪宋 DM 2017 款、车机 MX9A0、Android 4.2.2 / API 17，1024×600；用 iPhone 15 Pro Max / iOS 26.2.1 测试。没有在其他车型实车测试。
- **0.41.0-framework-beta** 是公开预览入口，加入用户自愿启用的环境匹配、版本历史和问题/筛选日志提交。APK 附在 GitHub 预发布页，供其他车机安装入口；本身不代表 CarPlay 已兼容。后续车型专属实验版仍由私人 OTA 按环境规则筛选。
- 历史清单有 52 个已归档 APK，排除了未发布的 0.54 候选版。0.34.0 标为稳定回退版本，0.40.0 标为已验证有线基线；其他归档版本都是历史测试包，不保证适配某台车机。

0.40.0 本身没有在线更新功能。其他车机可从 GitHub 预发布页下载 0.41.0 入口预览 APK，首次用 U 盘等方式安装；之后可在应用的“车型兼容”中查看对应该环境的实验版本和历史版本。旧版 APK 会下载到公共 `Download/DiPlayVersions` 目录，卸载当前 DiPlay 后文件仍保留。Android 要求降级前先卸载当前版本；卸载会清除 DiPlay 私有目录里的配对和设置数据。安装时系统仍会弹出确认。

## 用户主动同意后上传的内容

应用启动时不会访问版本服务器。只有用户打开车型兼容功能、阅读并同意说明后，才会查询匹配的版本目录。问题报告还需要用户填写问题描述，并再次确认提交。

车机环境字段包括：Android API 级别和版本、厂商/型号/设备/产品/主板/硬件代号、屏幕宽高/密度/刷新率、DiPlay 版本。报告还会包含用户输入的问题描述，以及最多 200 条筛选后的诊断事件；每条只保留事件类型、相对时间和有限的数值/布尔/状态字段，不上传完整原始日志。

应用不会上传 VIN、IMEI、序列号、MAC 地址、联系人、通话内容、语音或录音、屏幕内容、原始 USB 数据、API 密钥或完整原始日志。问题描述中不要填写姓名、电话号码等个人信息。服务器可能看到网络出口 IP。报告成功提交后只清除本次实际上传的本地日志条目，未上传和并发新增记录保留；本地日志按 24 小时期限清理。服务器原始报告也在 24 小时后自动清理。

**传输限制：当前公网接口使用未加密的 HTTP。** 网络路径上的设备可能读取或篡改请求。介意者请拒绝上传；拒绝或撤回同意都不影响本地有线 CarPlay。扩大测试范围前应恢复 HTTPS。

## 自动车型分组的范围

不需要手动选车型，也不需要邀请码。客户端根据上述白名单字段生成环境信息，服务器按每个版本登记的规则筛选测试版本。报告会用全部白名单字段生成更细的环境组。未来车型专属实验版可按 API、型号、分辨率等字段设定可见规则；当前 0.41.0 是公开入口预览，不按车型隐藏。

这些字段识别的是车机软件/硬件环境，不一定能识别真实的车辆品牌和年款。不同车机或固件可能报告相同字段。当前框架为以后在一个 APK 中按环境适配做基础，不代表其他车机已兼容，也不会自动修改代码或自动发布修复。
