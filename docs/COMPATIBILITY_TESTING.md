# 兼容性测试与隐私说明

## 车型识别

应用从 Android 系统读取车机制造商、型号、产品和 Android API 等常规属性，用于把相近配置归入同一车型组。不会用账号或邀请码区分测试者。少数厂商固件可能返回空值或通用值，因此报告中的用户问题说明仍很重要。

## 0.44.1 收集的诊断

- 车机型号、Android 版本/API、屏幕和应用版本等系统属性。
- 方向盘 Android KeyEvent 的键码、按下/松开、重复次数、来源、flags 和处理结果。
- 比亚迪 MCU 按键广播动作、键码、帧长度、有限帧头字段及应用是否发送 CarPlay 指令；不上传完整广播帧。
- Apple USB VID/PID、接口类别/子类/协议、端点能力、USB 授权与连接/断开时序，以及系统可读时的速度、配置和 USB 版本。
- USBMUX/NCM、认证和 AirPlay 启动阶段中经过白名单筛选的错误码、耗时和状态摘要。
- ALSA/音频路由环境诊断。
- 测试者分别填写 iPhone 12 与 iPhone 15 Pro 的连接情况、通话上行与下行的实际听音结果、方向盘语音键结果；iOS 版本可选填写。其他手机型号请在问题说明中写明准确型号。
- 用户主动输入的问题描述。请勿写姓名、电话号码、地址、车辆识别码或其他个人资料。

日志只保留经过字段白名单的事件，并优先保留音频、按键、USB、通话和连接阶段证据。上传大小与事件数量均有限制。服务器成功接收后，客户端只清理已确认上传的本地记录；失败时记录保留，便于重试。服务器报告按现行策略保留最多 24 小时。

## 不采集的内容

应用不会主动读取 USB 序列号、iPhone UDID、联系人、电话号码或通话录音，不上传完整 USB/网络数据包或 MAC 地址。测试者不应为本测试录制电话内容。问题说明可能包含测试者自行输入的信息，请只填写诊断所需内容。

## 传输与参与选择

上传接口使用未加密 HTTP，报告发送至维护者的私人服务器。网络路径上的第三方可能观察或修改传输内容。介意此传输方式或不希望将诊断资料提交给私人服务器的用户，请不要上传；可只在本地测试。

## 实测范围

目前有明确车上记录的组合为：比亚迪宋 DM 2017 款、MX9A0、Android 4.2.2 / API 17、1024×600、iPhone 15 Pro Max / iOS 26.2.1，有线 CarPlay。未在其他车型、车机固件或 iPhone 型号上确认兼容性。用户反馈的 iPhone 12 断连和方向盘语音键无响应仍待复测。
