# DiPlay 0.41.0 车型兼容框架测试版

## 发布与获取

这是按车机环境筛选的测试版。只有系统报告 Android API 17 且型号为 `MX9A0` 的设备能在私人更新目录中看到该测试 APK。GitHub 只发布说明和源码快照，不附测试 APK；目前公开 APK 仍是 0.40.0。

0.40.0 没有在线更新功能，因此需先用 U 盘或其他常规方式安装一次 0.41.0。安装后可在应用内查看后续匹配版本和 52 个历史归档 APK。选择历史版本后，APK 保存在公共 `Download/DiPlayVersions`。降级前要先卸载当前 DiPlay；卸载会清除应用私有数据，但不会删除公共下载目录里的 APK。历史清单排除了未发布的 0.54 候选版。

## 车机和测试范围

项目基于 [shihabal3amri/DiPlay](https://github.com/shihabal3amri/DiPlay) 移植，目标是 Android 4.2.2 / API 17、ARMv7。

目前唯一有真实车辆测试记录的组合是：比亚迪宋 DM 2017 款，车机 MX9A0，Android 4.2.2（API 17），iPhone 15 Pro Max / iOS 26.2.1，有线 USB 连接。0.40.0 的 1024×600 / 15 fps 投屏已在该组合上验证。**没有在其他车型、车机、手机或 iOS 版本上测试。0.41.0 新增的版本目录和报告上传尚未在车上实测。**

首个测试版本按 API 17 和系统型号 MX9A0 匹配；客户端还会读取厂商、设备/产品/主板/硬件代号以及屏幕尺寸、密度和刷新率，用于更细的环境分组。Android 属性表示车机环境，不一定能证明车辆品牌和年款；不同固件也可能返回相同值。

## 本版改动

- 增加“车型兼容”入口，提供自动匹配的测试版本和历史版本清单。
- 测试版按服务端车型规则筛选显示；历史 APK 作为归档版本提供下载。
- APK 下载到公共 Download 目录，卸载应用后文件仍保留；安装历史版本前需要手动卸载当前版，不再每个测试版单独附一个回退包。
- 增加用户填写问题并确认后提交报告的功能。日志只允许上传固定事件名称、相对时间和有限的数值/状态字段。
- 以已验证的 0.40.0 有线投屏为起点。本版建立车型分组和报告流程，不代表其他车机已能使用，也不会自动修改或发布代码。

## 隐私和数据

联网查询采用自愿加入方式。应用启动时不查询版本；首次联网前会展示上传说明，提交问题时还会再次确认。用户可在隐私说明页撤回同意。拒绝或撤回后，应用仍可本地运行有线 CarPlay。

上传的环境字段为 Android API/版本、厂商/型号/设备/产品/主板/硬件代号、屏幕宽高/密度/刷新率和 DiPlay 版本。报告还含问题描述和最多 200 条筛选后的事件。不会上传 VIN、IMEI、序列号、MAC、联系人、通话内容、录音、屏幕内容、原始 USB 数据、API 密钥或完整原始日志。请勿在问题说明里填写个人信息。服务器可能看到网络出口 IP。提交成功后只清除已上传的本地日志条目，未上传和并发新增记录保留；本地日志及服务器报告均按 24 小时期限清理。

**当前私人接口使用明文 HTTP。** 网络路径上的设备可能读取或篡改报告或版本目录流量。介意者请不要上传；扩大测试范围前需要恢复 HTTPS。
